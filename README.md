## 📖 Sobre o projeto

Repositório destinado aos estudos, atividades e projetos desenvolvidos na disciplina de **Desenvolvimento de Aplicações** da **Universidade de Mogi das Cruzes (UMC)**.

Aqui ficam reunidos os exercícios práticos, experimentos de Programação Orientada a Objetos (POO) e demais atividades propostas ao longo da disciplina.

## 📂 Estrutura do projeto

```
UMC-desenvolvimento-aplicacoes/
├── meu-app/       # Primeiro projeto/exercício da disciplina
├── poo-intro/     # Introdução à POO (classes, objetos e exemplos práticos)
├── LICENSE
└── README.md
```

## 🚀 Como executar

```bash
git clone https://github.com/kevinhsdev/UMC-desenvolvimento-aplicacoes.git
cd UMC-desenvolvimento-aplicacoes
```

Cada pasta contém um exercício independente — entre na pasta desejada e compile/execute os arquivos `.java` normalmente.
